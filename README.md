# Zalo — переводчик на русский

Расширение для [Zalo Web](https://chat.zalo.me/) в настольном Google Chrome 138 и новее.

## Установка

1. Скачайте [ZIP последней версии](https://github.com/silveriumX/zalo-ru-translator/releases/latest/download/zalo-ru-translator.zip) и распакуйте его.
2. Откройте в Chrome страницу `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `zalo-ru-translator`, внутри которой лежит `manifest.json`.
4. Обновите вкладку Zalo Web. Панель появится при открытии переписки.

## Как пользоваться

- **Входящие.** Русский перевод появляется под видимым текстовым сообщением. Для нового языка Chrome может попросить нажать «Перевести», чтобы скачать языковой пакет. Галочка «Входящие на русском» отключает показ перевода.
- **Ответ.** Напишите по-русски и выберите язык. «Отправить перевод» на панели над полем сразу отправляет перевод. Обычная кнопка Zalo отправляет содержимое поля.
- **Оригинал.** Выберите этот режим для обычной отправки без перевода ответа. Перевод входящих управляется отдельно.

Перевод применяется к тексту. Голосовые, фотографии и вложения обрабатываются самим Zalo.

## Языки и данные

По умолчанию язык определяется автоматически, а текст переводится на устройстве. Интернет может понадобиться для первой загрузки языкового пакета. [Языки и требования Chrome](https://developer.chrome.com/docs/ai/translator-api#supported-languages).

Для языка вне списка Chrome предусмотрен перевод через Google Cloud Translation. Откройте настройки по иконке расширения, сохраните собственный ключ проекта с включённым Cloud Translation API и разрешите доступ к домену Google Translation. Для входящего сообщения используйте «Через Google». Для ответа единственная кнопка меняется на «Отправить через Google», если язык недоступен в Chrome. Поддерживаемые языки указаны в [документации Google Cloud](https://docs.cloud.google.com/translate/docs/languages). Передаётся только текст, выбранный этим нажатием. Запросы учитываются по тарифу владельца ключа. Ключ хранится локально в Chrome и удаляется там же. Режим ответа и галочка входящих хранятся в настройках расширения Chrome. Расширение не сохраняет журнал переписки.

## Проверка из исходников

Загрузите папку `extension/` как распакованное расширение. Для браузерной проверки установите Playwright и его Chromium, затем запустите `node tests/browser.cjs`. Флаг `--real` запускает проверку на моделях Chrome с тестовыми фразами. Оба прогона используют отдельный профиль браузера и тестовую страницу без реальной переписки.

Если Chromium для тестов не содержит встроенных моделей, укажите путь к обычному Google Chrome в переменной `ZALO_CHROME_PATH` и запустите `node tests/browser.cjs --real`.
