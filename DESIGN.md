# Интерфейс

Русскоязычный пользователь читает переписку в Zalo Web и отвечает в привычном поле. Перевод входящего расположен под оригиналом и выделен линией слева. Над полем ответа одна строка с выбором языка и действием «Перевести ответ». После вставки Zalo отправляет текст своей обычной кнопкой. Ошибки появляются рядом с действием.

Нейтральный светлый фон #f3f7fb, текст #18304b, синий #17488d для действий, красный #942b35 для ошибок. Системный шрифт 13–14 px, отступы 8 и 12 px. Элементы переносятся на узком экране. Видимый фокус, без анимации. Внешний вид Zalo не копируется.
